# Koa AI Website

A small full-stack Progressive Web App for **Koa** — a chat assistant with six moods.

## Features

- Express + OpenAI Responses API on the server (API key never leaves the server)
- Mood system that shifts gradually from conversation signals
- Offline-capable app shell via service worker
- Installable PWA (when served over HTTPS)
- Demo mode when no API key is configured

## Run it

1. Install [Node.js](https://nodejs.org/) (18+ recommended).
2. Open a terminal in this folder.
3. Install dependencies:

npm install
